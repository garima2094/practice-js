## Problem

Given `n`, return a **function** `counter` that calls `counter()` and returns `n`, then returns `n + 1`, `n + 2`, and so on on subsequent calls.

## Examples

```javascript
const counter = createCounter(10);
counter(); // 10
counter(); // 11
counter(); // 12
```
